### How to run

```bash
pip install -r requirements.txt
python scripts/run_classical.py        # EDA, TF-IDF baselines, single-split ablation
python scripts/run_cv_ablation.py      # 5-fold cross-validated ablation
python scripts/run_neural.py           # TextCNN / BiLSTM (+ hand-crafted features)
python scripts/run_transformer.py xlm-roberta-base keep 3
python scripts/run_transformer.py google/muril-base-cased keep 4 96 16 --lr 3e-5
python scripts/run_ensemble.py         # probability ensemble, weights tuned on validation; writes outputs/best_model.json
python scripts/build_report.py         # regenerates the PDF from outputs/
python app.py                          # web demo with the best model (http://127.0.0.1:7860)
```
or open the notebook in Google Colab (GPU runtime) and run all cells.

To use the best model from the GitHub release: download `model_<name>.zip` from
https://github.com/KiranKhann/urdu-sarcasm-detection/releases, unzip it into `outputs/` (so that
`outputs/model_<name>/` exists next to `outputs/best_model.json`), then run `python app.py`.
